### 2.2 详细契约（每个接口）

**接口 1**：`POST /api/v1/xxx`

请求：
```json
{
  "field_a": "string, required",
  "field_b": "number, optional, default=0"
}
```

响应（成功）：
```json
{
  "id": "uuid",
  "status": "created"
}
```

错误码：
| HTTP | code | 含义 |
|---|---|---|
| 400 | INVALID_INPUT | 入参校验失败 |
| 401 | UNAUTHORIZED | 未鉴权 |
| 409 | CONFLICT | 重复创建 |
